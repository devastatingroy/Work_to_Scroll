# WorkToScroll

WorkToScroll 帮助用户通过工作或学习攒取娱乐时间；当时间用完后，它会限制继续使用目标娱乐应用。它面向希望减少无意识刷小红书、又不想把自律变成复杂任务管理的人。

目前这是一个持续进行真机验证的 Android 原型，不是公开发布版本。它正在验证工作计时、娱乐时间奖励和小红书限制能否在日常使用中形成可靠体验。

## 它怎样帮助你

1. 在首页开始工作，并在工作页主动开启监测。
2. 应用只在手机本机观察你是否大致在场，把符合条件的时间累计为工作进度，并自动换成娱乐时间。
3. 使用小红书时，保护开启后会按实际使用时间扣减余额；余额耗尽时提示你先回去工作。

摄像头只提供基础在场线索，不识别身份，也不代表能够证明你正在认真工作。它的作用是帮助形成可感知、可中断的工作节奏，而不是监控或评价工作质量。

## 你需要知道的事

- 工作监测由你在工作页主动开始；停止、离开工作页、锁屏或系统中断后不会补记未知时间。
- 娱乐时间有到期和夜间放松等规则，具体设置与当前行为以应用内说明和[产品要求](docs/SPEC.md)为准。
- 首次使用前，应用会说明使用情况访问、悬浮窗和摄像头各自的用途与影响；你可以自行决定是否授权，并随时停止保护或结束监测。
- Android 系统、目标应用和厂商后台策略都可能影响限制效果。强停、系统回收、锁屏恢复、音频和长期后台等场景仍在分别验证，不能承诺所有设备上的持续有效。

## 隐私

画面只在本机内存中用于当前人体观察，不保存照片或录像，也不上传连续摄像头画面、页面正文或完整浏览历史。应用不使用无障碍服务、麦克风或网络传输来完成当前原型的核心功能。

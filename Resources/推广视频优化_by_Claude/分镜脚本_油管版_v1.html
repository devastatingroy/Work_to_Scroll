Work to Watch —— 推广短片分镜脚本

油管版 · 竖屏 9:16 · 约 30 秒 · 平台 TikTok / YouTube Shorts · v1（照此拍摄 / 交剪辑）
⚠️ 开拍前必须先定的一件事：主角是"开发者"还是"纯普通用户"？
开场旁白 "我最烦的 app，是我自己写的" 是开发者口吻，而你要主角是普通人——两者有张力。
· 推荐（本稿默认）：保留"我自己写的"这个灵魂（为治自己的瘾、亲手做了个工具，最真实最打动人），但把造型和场景改普通——普通家居、普通穿着、普通电脑，去掉"满墙书 / 高领毛衣 / 苹果电脑 C 位"的精英感。开发者也是普通人。
· 备选（若要纯非开发者用户）：换开场旁白为 →「治好我 YouTube 上瘾的，居然是另一个 app。」其余不变。
通用拍摄须知（每条都影响成片是否"露馅"）
  • 实拍/录屏优先：屏幕内容、产品 UI、所有文字和数字——一律真实录屏（真开邮箱/文档打字、真截产品界面）。人物情绪实拍。AI 只允许用于氛围空镜，且必须去水印、挑无穿帮帧。别再让 AI 碰任何一个字。
  • 名称统一：全片只出现一个产品名（确认用 Work to Watch），不要和仓库名 WorkToScroll 混用。
  • 字幕规范：下表加粗的"字幕"必须上大字幕——居中偏下、粗体、描边或底色，保证静音也能读（平台约一半人首刷静音）。
  • 水印 / 合规：海外 TikTok/YouTube 可直接去水印；国内平台（抖音/小红书/视频号）AI 内容需标注，用平台自带的 AI 声明开关，别硬抠水印。
  • 设备一致：这是安卓产品，别让苹果电脑当 C 位；手机用安卓机出镜。

二、要提前做好的"真实屏幕"素材清单（录屏）

  1. 卡住的半封工作邮件（Gmail 草稿，含"上次编辑 3 小时前"）—— S1
  2. YouTube Shorts 快速上划的 feed —— S1
  3. 产品阻止页 00:00 / Work first. Watch later. —— S2
  4. 工作页"在场检测中 + 本地运行"标签 + 计时器走动 —— S3
  5. 邮件从一句写到几段的进度录屏（可加速）—— S4
  6. 产品到账界面 Watch Time +05:20 ✓ —— S5
  7. 正常看 YouTube + 顶部余额倒数 —— S6

录制方式：真开对应 app 打字/操作，手机投屏录（QuickTime/Scrcpy）或 OBS/手机自带录屏。零成本、完全可控。

三、静音必读的四句字幕（务必上大字）

  1. 我最烦的 app，是我自己写的。
  2. 想看？先把活干了。
  3. 它只看我在不在，判断全在手机本地，不上传云端。
  4. 我还是照样看……不过这回，活也干了点。

四、交片前验收清单

  • 逐帧暂停：屏幕上没有任何错字 / 乱码 / AI 水印。
  • 找个没看过产品的人看一遍，能复述出"没额度 → YouTube 被拦 → 去干活 → 换回时间"这个闭环。
  • 看完没有"这玩意在监控我"的不适感；记得住"本地运行、不上云"。
  • 关掉声音从头看一遍，仍能看懂。
  • 全片只出现一个产品名。
  • 结尾三件套齐全：产品名 + Slogan + CTA/获取方式。

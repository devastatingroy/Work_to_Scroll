# WorkToWatch 分镜整理包

本压缩包按两种内容方向整理：

## 01_广告型方案
适合：
- 官网 / 落地页 / 应用商店介绍
- 用户已经知道产品、愿意了解功能时使用

特点：
- 先讲产品机制
- 强调规则、流程、奖励与阻止逻辑
- 信息密度高，产品感更强

包含图片：
1. 广告型分镜_01_从想看视频到开始工作.png
2. 广告型分镜_02_完整流程版_18格.png
3. 广告型分镜_03_获得奖励与回到工作.png

## 02_Vlog型方案
适合：
- TikTok / Shorts / Reels 冷启动
- 面向第一次刷到内容的陌生用户

特点：
- 先讲人和故事
- 先让观众停下来，再自然带出产品
- 更像个人记录 / vlog / 第一人称体验

包含图片：
1. Vlog型分镜_01_我最烦的App是我自己写的.png
2. Vlog型分镜_02_我干了二十分钟就为了看这只猫.png

## 使用建议
- 冷启动引流：优先使用 Vlog型方案
- 承接转化：再补充广告型方案
- 两类内容可以配合使用，不建议在同一条首发冷启动视频里混太多
